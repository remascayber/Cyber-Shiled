# CyberShield

## Cybersecurity Threat Analysis and Educational Platform

CyberShield is an open-source educational cybersecurity application developed using Python and Tkinter.

## Features
- URL Risk Analyzer: Evaluates suspicious URL patterns and provides an educational risk score.
- Phishing Email Analyzer: Detects common phishing indicators in email messages.
- Attack Simulation: Interactive phishing awareness training in a safe environment.
- CTF Challenges: Beginner-friendly cybersecurity questions and challenges.
- Dashboard: Displays URL analysis statistics by risk level.

## Technologies Used
- Python 3
- Tkinter
- Python Standard Library

## How to Run
1. Install Python 3.
2. Open PowerShell in the project folder.
3. Run: python gui.py

## Educational Purpose
CyberShield is intended for learning and awareness only. Its risk scores are heuristic and do not guarantee that a website or email is safe.
